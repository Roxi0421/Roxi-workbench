# 个人工作台 · PWA

一个可安装到手机桌面的纯前端个人工作台，包含：每日工作日程、智能运动计划（联动手环）、智能睡眠管理、护肤提醒、阅读计划、英语×三电知识。所有「今日内容」由 **日期 + 配置 + 当日手环数据** 确定性生成，跨过午夜或重新打开自动重算（实现"每天 00:00 更新"）。

## 目录结构
```
index.html              页面入口
manifest.webmanifest    PWA 清单（安装到桌面）
sw.js                   Service Worker（离线 + 可安装）
assets/
  css/style.css         样式（移动端优先）
  js/config.js          ★ 你的可调参数（时间/目标/书单/节假日）
  js/content.js         ★ 视频库 + 三电英文文章库
  js/app.js             主逻辑（计算与渲染）
  icons/                PWA 图标
```

## 如何使用 / 安装到手机
PWA 安装到手机桌面**需要 HTTPS 访问**（localhost 除外）。两种做法：

**① 本机预览（电脑浏览器，快速验证）**
```bash
cd /workspace
python3 -m http.server 8123
# 浏览器打开 http://localhost:8123
```

**② 部署到公网（手机可"添加到主屏幕"）**——任选其一：
- **GitHub Pages**：把本目录推到仓库，Settings → Pages 开启；或 `npx vite`/静态托管。
- **Vercel / Netlify**：拖拽本目录即可，自动HTTPS。
- **Cloudflare Pages / 任意静态托管**同理。
部署后**用手机浏览器打开该 HTTPS 地址 → 点浏览器菜单"添加到主屏幕"**，即得到一个类似原生 App 的工作台（可离线、全屏、每天自动刷新）。

## 如何每天用
1. 早晨打开工作台，点右上角 **「同步今日手环数据」**，填入：睡眠时长、睡眠质量(1–5)、静息心率、疲劳度(1–5)。
2. 运动模块会据此**智能升级/降级**（状态好→高强度瘦腿燃脂；睡眠不足/疲劳→降级为拉伸瑜伽），睡眠模块同步倒推**建议入睡时间**。
3. 勾选完成的日程/任务，进度按天保存在本机。
4. 阅读模块显示今日章节/页数 + 思考题；英语模块推送 3 篇三电英文候选，点选任一篇看**中英文对照**。

## 如何调整（对话式）
直接把需求告诉我（WorkBuddy），我来改 `config.js` / `content.js`；你也可以自己改这两个文件后刷新页面。常见调整：
- 改时间（午休、通勤、护肤时刻）、运动时段（工作日/周末）；
- 换/加运动视频、三电文章；
- 设置节假日 `holidays` 与调休补班 `workdays`（格式 `"2026-10-01"`）；
- 更新大腿围实测值与日期（目标进度展示用）。

## 已知边界
- "每天 00:00 自动更新"在纯静态网页下，通过「按日期确定性生成 + 午夜/重开自动重算」实现；若需要**真正的后台静默推送**（不打开也更新、实时联网抓文章），需加一个轻量后端/定时任务，可后续扩展。
- 手环数据为**每日手动同步入口**（无真实手环 API 对接）；智能判定规则已按你的要求实现。
